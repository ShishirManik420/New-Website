# অক্ষর — Bengali Type Studio

An original, free Bengali typography studio starter inspired by the *idea* of a modern type foundry, but not a copy of any existing website.

## Files
- `index.html` — page structure/content
- `style.css` — responsive visual system
- `script.js` — mobile navigation + demo form
- `assets/` — put your own images/fonts here

## Run
Open `index.html` directly in a browser.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload these files to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/root`.
5. Save. GitHub will publish the site.

## Customize
Replace the demo typeface names and text with your own projects. Add licensed images/fonts inside `assets/`.
